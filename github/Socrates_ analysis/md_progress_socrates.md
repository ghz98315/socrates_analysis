### v1.7.6 - 家庭管理增强 + 知识图谱 (2026-03-09)

  - 孩子学习概览列表（错题数、掌握数、今日时长、薄弱点）

  - 任务管理页面 `/tasks`
  - 支持任务类型：练习、复习、错题本、自定义
